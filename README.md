# Shopping Calculator 

## Description
Shopping Calculator  is a console-based Java application that calculates the total cost of purchased products and generates a shopping receipt.

## Features
- Accepts customer and product information.
- Calculates individual product totals.
- Calculates the shopping subtotal.
- Applies a 10% discount when the subtotal is R1,000 or more.
- Displays a formatted shopping receipt.
- Uses Java Scanner for user input and loops for processing multiple products.

## Technologies Used
- Java
- Java Scanner
- Arrays
- For Loops
- Conditional Statements
- printf formatting

## How to Run
1. Clone this repository.
2. Open the project in your preferred Java IDE.
3. Compile and run `Main.java`.
4. Follow the prompts displayed in the console.
